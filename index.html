01 · Arsitektur

Bagaimana halaman web dinamis bekerja?

PHP berjalan di server, bukan di browser. Browser hanya menerima hasil akhirnya berupa HTML. Tekan Jalankan untuk melihat perjalanan satu request.

  1. Pengguna membuka localhost/crud/index.php; browser mengirim HTTP GET.
  2. Apache menyerahkan file .php ke PHP interpreter.
  3. PHP mengirim query SELECT * FROM mahasiswa lewat MySQLi.
  4. MySQL mengeksekusi query pada tabel.
  5. MySQL mengembalikan result set (baris-baris data) ke PHP.
  6. PHP merangkai data menjadi HTML lalu mengirim response 200 OK.
  7. Browser menampilkan tabel. Kode PHP tidak pernah terlihat oleh pengguna.
Tekan ▶ Jalankan untuk memulai animasi…
Inilah alasan file PHP harus dibuka lewat http://localhost/…, bukan dengan klik dua kali file (file:///). Tanpa web server, kode PHP tidak dieksekusi.
